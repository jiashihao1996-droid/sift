# 拍摄时间排序、连拍分组与组内对比

状态：① 拍摄时间排序已实现；② 分组与组内操作、③ Survey 视图待做。
拍板：2026-10-04

## 背景

- 照片只按文件名排序。双机、双卡混在一个文件夹，或计数器回绕（DSC09999 → DSC00001）时，顺序被打乱，同一时刻的照片被拆散。
- 连拍要逐张看、逐张标，没有「一组」的概念；对比只有 `C` 的 2-up。
- 竞品参考：Lightroom Classic 按拍摄时间自动堆叠（间隔滑块）、Narrative Select 的 Scenes、Aftershoot 拒绝整组、FastRawViewer 4-up、OptiCull 同步缩放。

## ① 按拍摄时间排序（已实现）

- 扫描时为每组读取拍摄时间：`DateTimeOriginal` + `SubSecTimeOriginal` + `OffsetTimeOriginal`；没有时退回 `DateTimeDigitized` 及其配套标签。不用 `DateTime`（修改时间）和文件修改时间：拷贝、导出后不可靠。
- 读取来源：有 JPG 先读 JPG；JPG 没有记录时读 RAW；纯 RAW 读 RAW，不读缓存里的预览图。
- 只读文件开头：一次读入前 16KB，在内存里定位 EXIF；偏移超出这 16KB 才回到文件按需读取，从不整读文件（`media/capture_time/`）。

  | 格式                                              | 读取位置                                            |
  | ------------------------------------------------- | --------------------------------------------------- |
  | JPG                                               | 逐段跳过，找到 APP1/EXIF 里的 TIFF                  |
  | TIFF 系 RAW（ARW、NEF、CR2、DNG、ORF、RW2、PEF…） | IFD0 → Exif IFD                                     |
  | RAF                                               | 文件头第 84 字节给出的内嵌 JPG，再按 JPG 读         |
  | CR3                                               | `moov` → Canon `uuid` → `CMT2`（本身就是 Exif IFD） |
  | 其他（X3F 等）                                    | 视为没有拍摄时间                                    |

- 排序规则（`src/core/sorting.ts`）：
  - 默认按拍摄时间；状态栏左侧「拍摄时间 / 文件名」按钮切换，不设快捷键。排序方式是全局偏好，存 localStorage（`sift.sortOrder`），不按文件夹记，不写进进度。
  - 拍摄时间相同的，按文件名自然序。
  - 文件夹里每张有时间的照片都带时区时，换算成 UTC 比较；只要有一张没带，就全部按相机本地时间比较。这样规则可传递，混用新旧机身时结果可预测。
  - **没有拍摄时间的照片排在末尾，按文件名自然序**；按拍摄时间排序时状态栏提示「N 张无拍摄时间，排在末尾」。
  - 按文件名排序时恢复扫描返回的顺序（Rust `sort_naturally`），前端按扫描时记下的名次排，不重新实现自然序。
- 切换排序时停在同一张照片，对比基准图也跟着走；撤销栈按照片 id 记录，重排后撤销仍作用于原来那张。
- 进度按文件路径保存位置，两种排序下都回到上次那张。
- 不做：校正两台机身之间的时钟偏差。

### 扫描耗时（5000 组 JPG + RAW，合成样本，Apple Silicon 内置 SSD，release 构建）

| 场景                                 | 之前    | 之后    |
| ------------------------------------ | ------- | ------- |
| 热缓存                               | ~25 ms  | ~70 ms  |
| 冷缓存（磁盘映像每轮重新挂载，3 轮） | ~120 ms | ~530 ms |

每张照片多出一次打开文件和一次 16KB 读取。慢速存储卡上会更明显；如果实际体验受影响，再改成先返回列表、拍摄时间随后补上。复测：`SIFT_SCAN_BENCH_DIR=<文件夹> cargo test --release scan_benchmark -- --ignored --nocapture`。

## ② 连拍分组（待做）

- 切组：当前顺序里相邻两张都有拍摄时间，且相差不超过间隔，就算同组；没有时间的照片各自成组。两种排序下都分组（按文件名时双机交错，组会少一些）。
- 间隔默认 2 秒；状态栏「连拍」弹层可选 关 / 1 / 2 / 5 / 10 / 30 / 60 秒，全局偏好，不设快捷键。
- 缩略条只给 2 张及以上的组画边界（组间细缝 + 组下方连拍色细线）；主图状态栏显示「组内 3/7」。组边界由顺序和拍摄时间一次算好，不依赖标记状态，按键标记时不重新计算。
- 键位：
  - `]`：下一组第一张（单张照片等同 `→`）。
  - `[`：在组中间回到本组第一张；已在第一张时到上一组第一张。
  - `Shift+F`：精选当前这张，组内其余**未标记**的标删除；已精选、已删除的保持不动。撤销算一步。
  - `Shift+X`：整组未标记的标删除。撤销算一步。
  - 组内一键操作后跳到下一组第一张；`L` 开启时停在原地。
- 纯规则放 `src/core/grouping.ts`；撤销条目支持一次改多张。

## ③ Survey 视图（待做）

- `N` 进入 / 退出，显示当前组，最多同时 4 张（2 张并排、3–4 张 2×2）；超过 4 张时显示焦点附近的 4 张，窗口随焦点滑动并标出「5–8 / 12」。单张照片按 `N` 提示「这张不在连拍组里」。
- 焦点就是当前照片：`←` / `→` / `Space` 在组内移动，到组首、组尾停住；`[` / `]` 换组并保持 Survey。
- `F` / `X` / `Shift+F` / `Shift+X` 作用于焦点；标记后焦点移到组内下一张，到组尾停住；`L` 开启时不动。删除的照片原位变暗加角标，不重新排版。
- 缩放同步：同一缩放比例，对准每张图上同一相对位置。
- `C` 与 `N` 互斥，进入一个先退出另一个；`Esc` 退出当前的那个。`L`、`0`、`1`、`Z`、`+`、`-`、滚轮含义不变。
