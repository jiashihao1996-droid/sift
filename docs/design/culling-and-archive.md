# 筛图交互与归档重设计

状态：归档与交互方案均已确认，按「实现顺序」逐个 PR 实现。
起草：2026-10-03

## 背景

- 「跳过」实际承担两件事：记录「看过」（进度、标记后跳到下一张未处理、总结卡），以及归档时「保留」（精选 + 跳过移入 `JPG/`、`RAW/`，未处理留原位）。
- `→` / `Space` 是 `markSkip`，回看时会把 ★、删除改成跳过；没有纯前进键。
- 标记后跳到「下一张未处理」，回看时改一张会被甩到前沿；取消标记不进撤销栈。
- `slideDirection` 是死状态（上游 6998a4c 删掉了 slide `<Transition>`），PR #24 修的值没人读。

结论：去掉「跳过」，也不引入隐式的「看过」状态。照片只有 **精选 / 删除 / 未标记** 三种状态。

## 归档（已定）

| 状态   | JPG                             | RAW          | XMP                                        |
| ------ | ------------------------------- | ------------ | ------------------------------------------ |
| 删除   | 进系统回收站（`trash::delete`） | 进回收站     | 进回收站                                   |
| 未标记 | 原地不动                        | 移入 `RAW/`  | 跟 RAW 进 `RAW/`；无 RAW 时随 JPG 原地不动 |
| 精选   | 移入 `精选/`                    | 移入 `精选/` | 移入 `精选/`                               |

```
DCIM-0915/
├── DSC_0002.JPG          ← 未标记：JPG 原地
├── RAW/
│   └── DSC_0002.ARW      ← 未标记的 RAW（+ XMP）
└── 精选/
    ├── DSC_0003.JPG      ← 精选：JPG + RAW + XMP 同一文件夹
    └── DSC_0003.ARW
```

细则：

1. **删除不是永久删除**，仍只用 `trash::delete`（项目安全规则）。
2. **扫描纳入 `RAW/` 子文件夹参与配对**：重开原文件夹时，原地 JPG 与 `RAW/` 中同 stem 的 RAW 重新配对；删除时一起进回收站；再次归档时已在 `RAW/` 的文件不动。否则重开后全是「无 RAW」，删 JPG 会留下孤儿 RAW。
3. **重名不覆盖、保持配对**：未标记照片的 RAW 在 `RAW/` 中重名而加 `_N` 时，原地的 JPG（和随 JPG 的 XMP）同步改名为同一 `_N`（同目录改名，同样先 `create_new` 占位）。`精选/` 内三者同目录，沿用 `paths::unique_paths_sharing_stem` 的共用后缀规则。
4. **纯 RAW**：精选 → RAW 进 `精选/`，并把缓存预览图存为同名 JPG 放在旁边（与现有归档一致）；未标记 → 只把 RAW 移入 `RAW/`，不往原文件夹写新文件（靠第 2 条重开时仍可见）。
5. **文件夹名**：`精选`。
6. **导出保留**：只导出精选，复制到用户选择的目录，行为不变。
7. **归档确认框**写明：精选 X 组 → `精选/`；删除 Y 组 → 回收站；其余 Z 组：JPG 不动，RAW → `RAW/`。
8. 筛到一半也可以归档：未标记的 JPG 留在原地，重开原文件夹可继续筛。归档成功后清除该文件夹的进度（同现状）。
9. 不再有 `JPG/` 文件夹。
10. 改动 archive / scan 必须附带临时目录的 Rust 测试（项目规则）。

## 标记与交互（已定）

- 状态：精选 / 删除 / 未标记。去掉「跳过」：键位、ActionBar 按钮、状态栏、筛选图库、总结卡、README、快捷键帮助一并去掉。
- `F` 切换精选；`X` / `Delete` 切换删除；去掉 `Backspace`。两键之间可直接互换。
- 标记或换标记后前进到下一张（i+1）；不再跳「下一张未处理」，也不回绕。
- 取消标记（再按同一键）停在当前照片。
- `←` / `→` / `Space` 纯导航，允许按住连发；`F` / `X` / `Delete` 忽略 `e.repeat`。
- 撤销：标记、换标记、取消标记各算一步；撤销恢复原状态并跳回那张；不做重做，`Cmd+Shift+Z` 不再触发撤销；撤销栈为空时不提示「已撤销」。
- 进度：保存标记与当前位置；没有标记但位置不在第一张时也保存；旧进度文件中的 `skipped` 视为未标记，其余标记照常恢复。
- 进度条按位置（第 N 张 / 总数）。
- 删除 `slideDirection`、`slideDirectionTo`、slide CSS、`activePairs`，保持瞬时切换。

- 标记反馈：底部短提示「★ 精选 · 文件名 · 撤销」约 1.2 秒，新的替换旧的（修 `showToast` 计时器不清理）；主图常驻状态角标，替换写反的删除闪烁；ActionBar 按压动效对键盘标记也生效。
- 总结卡：在最后一张上再前进（→ / Space / 标记）时弹出；「继续浏览」关闭，回看改标记不再弹。
- 切换照片时保持缩放比例与位置，旋转仍复位。
- 预加载：按前进方向预载接下来几张、后面 1 张；用 `decode()`；改成真正的 LRU。
